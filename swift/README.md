# Swift Crash Course Prep (BOA Global Tech)

This workspace is a lightweight Swift learning environment focused on syntax, compilation, and execution.

## Quick Start

1. Create a source file:

   ```swift
   // src/HelloWorld.swift
   print("Hello, Swift")
   ```

2. Compile:

   ```bash
   swiftc -o out/HelloWorld src/HelloWorld.swift
   ```

3. Run:

   ```bash
   ./out/HelloWorld
   ```

See `md/swift-basics.md` for a short command/reference guide and mini projects.

## Prerequisites

- Swift 5.0+ installed
- macOS or Linux with Swift toolchain

## Projects

- **DataTypes.swift**: Variables, optionals, and type inference
- **Calculator.swift**: Functions and control flow
- **StringManipulation.swift**: Working with Strings and Collections
